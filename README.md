# 胶片分镜条核对台 / 胶片装运台

一个纯前端本地应用，无第三方依赖、无后台，直接打开 HTML 即可使用（也可在本目录启动静态服务）。两页通过同一个 `localStorage` 键同步数据，任意标签页修改都会实时同步到另一个页面。

## 核对台 `index.html`

整理纸质放映胶片片段：录入、拖拽调整放映顺序、统计总时长、按颜色偏移/关键词筛选，并汇总破损与偏色提醒，导出核对清单。

## 装运台 `shipping.html`

把片段选进带编号的运输箱并登记防潮剂：

- 每箱可填箱号、限重（克）与防潮剂包数；重量按「片长秒数 × 20g + 防潮剂 30g/包」估算，超重显示红色超标线。
- **封箱判定**：箱内有破损或偏色片段、同一片段落入两箱、超重，或箱内为空时，该箱暂不能封；页面逐条列出阻断原因，已装条目始终保留装入顺序。防潮剂为 0 只作提醒，不阻断封箱。
- **封箱锁定**：合格后一键封箱，记录封箱时间、封箱重量与条数，之后不能增删改。
- **收货核对**：对已封箱逐条登记「新划痕 / 受潮」，提交后只有受影响片段退回右侧「收货后待检」，其余条目随箱照常封存；待检片段复检通过可移出。
- 顶部统计装箱数（已封/总箱）、已装片段数与待检数；未装箱片段会在顶部红字提醒，避免漏带。
- 筛选（待装/已装/破损偏色/退回待检 + 颜色 + 关键词）并导出含每箱明细、阻断原因、漏带与退回清单的文本装箱单。

## 文件分工

| 文件 | 作用 |
| --- | --- |
| `store.js` | 共享数据层：本地读写、默认数据、迁移、估重/防潮剂常量、删除片段时级联清箱、格式化与转义 |
| `app.js` / `index.html` / `styles.css` | 核对台页面与基础样式（两页共用） |
| `shipping.js` / `shipping.html` / `shipping.css` | 装运台页面逻辑、结构与专属样式 |
