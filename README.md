# 胶片分镜条核对台 / 胶片装运台

一个纯前端、无依赖、无后台的本地应用，由两个页面组成，数据保存在浏览器 localStorage 中并在两页之间自动同步：

- `index.html` — **胶片分镜条核对台**：录入片段、拖拽调整放映顺序（即装箱顺序）、统计时长、筛选偏色、生成破损与收货待检提醒、导出清单。
- `shipping.html` — **胶片装运台**：把片段选入带编号的运输箱、登记防潮剂袋数与装箱上限，封箱判定与锁定，收货核验（新划痕 / 受潮退回待检），装箱数统计、筛选与装箱单导出。

直接用浏览器打开 HTML 即可使用，也可在本目录启动任意静态服务访问。两页同时在不同标签页打开时，一边的改动会通过 `storage` 事件实时同步到另一边。

## 装运规则（判定集中在 `js/store.js`）

- 运输箱自动编号（No.001 起，编号单调不复用），条目始终按核对台的放映顺序排列。
- 箱内有**破损**或**偏色**片段、或**同一片段同时落入两个运输箱**时，两口箱都不能封箱，已装条目保留不动。
- 空箱不能封；未放防潮剂、超出装箱上限（超重预警）会提示但不阻断。
- **封箱后锁定**：不能再装入/移出/改防潮剂/删箱。
- 收货时在封存箱条目上勾选「新划痕」或「受潮」：只把受影响片段移到「收货待检」，箱内其余条目照常封存，箱保持锁定；误点可撤回，片段按原序归位。
- 待检片段复检通过后回到片段池，由装运台重新装箱。

```
shipping.html     装运台页

css/shipping.css  装运台专属样式
js/util.js        格式化与转义
js/store.js       共享数据层：状态、持久化、跨页同步、装运领域判定与全部修改动作
js/desk.js        核对台页渲染与交互
js/shipping.js    装运台页渲染与交互
```
